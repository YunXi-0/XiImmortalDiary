# 修仙游戏 - 项目交接文档

## 项目概述
竖屏修仙游戏，纯文字+按钮实现，面向手机 Android WebView。无素材，浅色主题白色背景。

## 仓库
- GitHub: https://github.com/YunXi-0/XiImmortalDiary.git
- 存储在 localStorage，键名 xiImmortalSave，当前 SAVE_VER=4
- 推送时机：用户说"上传"时才 git push

## 文件结构
- outputs/index.html — HTML骨架 + CSS样式
- outputs/game.js — 全部游戏逻辑
HTML 通过 script src=game.js 引入 JS。

## 重要：编码问题
game.js 中所有中文文本必须用 Unicode 转义写入，不能直接写中文字符。
写入方式：用 node 脚本写文件（通过 exec_command），或用 apply_patch 工具。
绝对不要用 PowerShell 的字符串替换操作中文内容，会因转义问题失败。

## 重要：大文件修改策略
不要用 PowerShell 字符串替换修改 game.js。推荐方式：
1. 用 apply_patch 重写整个文件
2. 用 node 脚本写入临时 .js 文件，exec_command 运行
3. 小改动可用 node -e 一行命令
**重要：每次修改后必须用 `require('vm').createScript(s)` 验证 JS 语法**

## 界面结构（6个Tab）
1. 主界面 — 境界、修为进度条、修炼/突破按钮
2. 游历 — 目的地选择、游历（前进/探索/返回）、战斗
3. 存储 — 装备栏 + 仓库 + 背包
4. 商店 — 铜钱显示、出售物品
5. 制作 — 炼丹/饰品配方
6. 信息 — 属性/统计/图鉴 三个子tab（每1秒自动刷新，切走时停止）

## 状态管理
playerState = 'idle' | 'cultivating' | 'traveling'（互斥）

## 修炼
- 每10秒+10修为（通过 applyCultivateBonus 应用饰品加成后写入）
- 修炼中每秒恢复1%最大血量
- 突破不中断修炼
- **修炼按钮始终显示，圆满后仍可继续修炼增加修为**

## 境界系统

### 练气期（13层 + 圆满 = 14个stage，stageIdx 0~13）
- 每层命名：练气一层、练气二层、...、练气十三层、练气圆满
- 突破需求：(i+1)*100，即一层→二层100、...、十三层→圆满1300

### 新增境界（每个4阶段：前期/中期/后期/圆满）
筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 渡劫
stageIdx 14~41（共28个stage）

### 突破类型
- **阶段突破**（同境界内）：按钮显示"阶段突破"，所需修为 = 上一阶段 ×1.2（向上取整到10）
- **境界突破**（跨境界）：按钮显示"境界突破(需微弱灵气残影×15)"，所需修为 = 上一阶段 ×2（向上取整到10）
- 练气圆满→筑基前期修为需求固定2000（非公式计算）

### 突破所需修为数值参考
| 突破 | 修为 |
|---|---|
| 练气十三层→圆满 | 1400 |
| 练气圆满→筑基前期 | 2000（+15微弱灵气残影） |
| 筑基前期→中期 | 2400 |
| 筑基中期→后期 | 2880 |
| 筑基后期→圆满 | 3460 |
| 筑基圆满→金丹前期 | 6920 |

### 属性百分比加成
每次突破增加属性百分比（血量/攻击/防御通用）：
- 练气阶段突破：+1%（共13次 = 13%）
- 练气境界突破：+2%（= 练气阶段突破×2）
- 筑基阶段突破：+2%（= 练气境界突破的奖励）
- 筑基境界突破：+4%（= 筑基阶段突破×2）
- 金丹：阶段+4%，境界+8%，以此类推翻倍

### 突破物品需求
- 练气圆满→筑基前期：需要15个微弱灵气残影（背包中检查，突破后消耗）
- **目前筑基的境界突破未开放**（筑基圆满→金丹前期暂不可突破，点击弹提示）

### getEquipSlots()
目前固定返回1（练气期仅解锁1个装备栏），后续解锁规则待定。

## 属性计算
- 基础：血量50、攻击5、防御0、自然恢复0

- 血量显示1位小数，攻击防御显示2位小数

- equippable:true 的物品可装备
- **装备类物品弹窗**：品质正常显示，不显示大小/可堆叠数量，显示装备效果描述，maxStack=1

## 制作系统
一品灵草丹 | 炼丹 | 灵草x5 | 100% | 10次 | +1血量+0.1攻+0.1防
灵草结 | 饰品 | 灵草x20 | 100% | 不限 | 修为获取+10%
- 制作界面弹窗仅显示描述和效果（用 showCraftPopup，不用 showModal）

## 修为获取加成（灵草结）
- applyCultivateBonus(base) = base * (1 + getCultivateBonus())
- getCultivateBonus() = 每件灵草结 +10%（可叠加，同时只允许装备1件所以最多+10%）
- **加成仅作用于"获取修为"的增量**，不是作用于总修为
- setExp(v) 不再自动应用加成，只有修炼tick和灵气残影吸收手动调用 applyCultivateBonus
- 修炼tick: setExp(exp + applyCultivateBonus(10))
- 灵气残影吸收: setExp(exp + applyCultivateBonus(bonus))
- 效果示例：原获取100修为→装备后获取110；原获取10→装备后获取11
